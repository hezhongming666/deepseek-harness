## 1. 部署拓扑与环境

### 1.1 环境矩阵

| 环境 | 用途 | 形态 | 数据 |
| --- | --- | --- | --- |
| dev | 日常开发、单组件调试 | 本机 Docker Compose | 合成数据 |
| ci | 流水线自动化验证 | 临时容器，按次销毁 | 合成数据 |
| staging | 全链集成、虚拟调试验收 | 工程区服务器 + 虚拟 PLC（PLCSIM/TwinCAT 仿真） | 脱敏样本 |
| prod | 真实项目执行 | 工程区（云端编排）+ 现场边缘节点 | 真实，加密存证 |
| edge | 现场离线任务 | 边缘节点，可断网运行，回连后同步 | 现场数据只读 |

### 1.2 网络分区（对应 IEC 62443）

| 区 | 访问规则 |
| --- | --- |
| 办公网 | 仅允许访问门户与审批面板（HTTPS） |
| 工程区（dev/ci/staging/prod 服务） | Agent 平台所在地；出站仅白名单（模型 API、组件许可服务器） |
| 生产网 | Agent 只读（OPC UA 订阅）；写入必须经闸门审批；无默认路由 |
| 边缘节点 | 断网可运行；与工程区通过 VPN/专线按需同步 |

### 1.3 基础设施清单（最小可用规模）

| 资源 | 规格建议 | 说明 |
| --- | --- | --- |
| 工程区服务器 ×2 | 32C/128G + 1TB NVMe | 编排器、验证器、仿真、数据库（主备） |
| GPU 节点 ×1（可选） | 24G 显存 | 本地模型/微调；否则全走 API |
| 边缘节点 ×2 | 16C/32G 工业级 | 现场执行、断网缓存 |
| 备份存储 | 对象存储异地副本 | RPO≤24h、RTO≤4h（示例目标） |
| Windows 工程机 ×2 | 带 TIA Portal/EPLAN/仿真许可 | PLC/E-CAD 适配器宿主机（TIA Openness 仅 Windows） |
| 许可 | TIA Portal Openness、CODESYS、EPLAN API、仿真平台 | 按供应商清单采购 |

## 4. 关键接口契约（先行冻结）

1. **Agent 产出契约**：所有 Agent 输出统一信封——`{ task_id, agent, model_version, prompt_version, output: {structured | artifact_paths}, evidence[], timestamp }`；结构化元数据过 JSON Schema（对应架构 §7.1）。
2. **验证器契约**：`verify(kind, artifact_path, options) → { pass, evidence[], diagnostics[] }`；验证器只读产物、不写业务库、输出全证据。
3. **适配器三接口**：`import_project(src) / export_asset(asset) / run_check(check_spec)`；适配器禁止持有审批权限。
4. **追溯事件**：需求/设计/实现/测试/变更五类节点，边为可追溯关系；事件不可变，append-only。
5. **闸门 API**：`request_gate(gate_id, context) → approval_payload`；放行结果只能来自人类裁决或规则引擎，Agent 身份不可调用放行。

## 5. 工程任务分解（Sprint 级）

### 阶段一（S1–S8，每 Sprint 2 周）

| Sprint | 任务 | 验收（对应落实计划书里程碑） |
| --- | --- | --- |
| S1 | 脚手架：monorepo、Docker Compose、CI、资产仓库、追溯库 schema、审计日志 | 全组件可启动；事件可写入可查询 |
| S2 | 需求解析 Agent v0 + 需求矩阵 schema + 澄清问题生成 | 5 份历史协议抽样：条目提取召回 ≥90% |
| S3 | PLC 程序生成 Agent + TIA Openness 适配器（import/export/compile） | 模板库外项目也能生成工程文件并导入编译 |
| S4 | 编译/Lint 验证器 + 内环（诊断→修复→重验，≤3 次） | M1：基准集首生成编译 ≥80%，修复后 ≥95% |
| S5 | Agents4PLC 基准集接入 + 指标看板（Prometheus/Grafana） | 基准可一键重跑；指标入看板 |
| S6 | Eigen 试用部署 + RealPLC 闭环对照部署（双路） | M2：对照报告（质量/成本/锁定度） |
| S7 | 知识库种子入库（模板 ≥20、检查清单 ≥5、案例 ≥10）+ RAG 接通 | 检索命中率监控上线；低命中显式标示 |
| S8 | 阶段一验收：集成测试 + Go/No-Go 材料 | 阶段一验收条件全绿 |

### 阶段二（S9–S16）

| Sprint | 任务 | 验收 |
| --- | --- | --- |
| S9 | E-CAD 适配器（EPLAN API）+ 电气 Agent | E-CAD 规则检查通过样例项目 |
| S10 | 仿真适配器（PLCSIM/SIMIT/Factory IO 多通道）+ 仿真 Agent | 虚拟调试用例自动生成并执行 |
| S11 | SemaPLC 行为验证模块集成（强制输入 + 变量轨迹） | 行为验证证据进入仿真报告 |

### 阶段三（S17–S22）/ 阶段四（S23 起）

- 阶段三：规则化闸门引擎（A2 放行规则）、审计导出包、供应商 SLA 与版本冻结、LLM 主备切换演练（M5–M6）。
- 阶段四：运维 Agent + OPC UA 只读接入 + 时序库、学习管线常态化、行业模板扩展（M7–M8）。

## 6. CI/CD 与测试策略

| 层 | 内容 | 频率 |
| --- | --- | --- |
| 单元 | verifiers 判例集、adapters 契约 mock、agents 纯逻辑 | 每次提交 |
| 集成 | 契约测试：Agent→验证器→追溯→闸门链路（合成数据） | 每日 |
| 端到端 | staging 虚拟 PLC 环境跑样例项目全流程（需求→仿真） | 每 Sprint 末 |
| 回归 | Agents4PLC 基准集 + 自有回归集 + 已交付项目关键产物重编译/重仿真 | 组件/模型升级时强制 |
| 演练 | 供应商切换（≤1 工作日恢复）、备份恢复（季度） | 按计划 |

发布门禁：CI 全绿 + 回归不劣化 + 变更单（含闸门/提示词变更审批记录）。任何发布必须可回滚：资产回滚走 Git revert，组件回滚走版本冻结清单，模型回滚走主备切换。

## 7. 安全加固清单

- [ ] 最小权限账号：Agent 按域分配（工程区读写/生产网只读/在线写入需审批）
- [ ] 密钥全部入 Vault，禁止落盘明文；TIA/CODESYS/模型 API 凭据轮换 ≤90 天
- [ ] 全量决策日志加密存证（输入/输出/验证/闸门/人工介入），支持按项目导出审计包
- [ ] 跨项目知识检索脱敏；涉密项目全私有化部署、无外呼
- [ ] 边缘节点磁盘加密、防篡改引导；回连同步走双向认证
- [ ] 依赖与镜像漏洞扫描入 CI；上游组件版本升级先回归后上线

## 8. 运维 Runbook（常见故障）

| 故障 | 处理 |
| --- | --- |
| PLC 编译失败且内环耗尽 | 升级包自动生成（上下文+证据+诊断），闸门裁决；禁止静默跳过 |
| 仿真超时/模型不收敛 | 缩短用例集重跑定位；保留失败证据；标记行为模型待校准 |
| 模型 API 不可用 | 自动切备用供应商；关键验证器本地化不受影响（架构 §5.5） |
| 供应商组件 API 变更/停服 | 冻结版本回退 + 触发替换预案（适配层换源，Agent 不动） |
| 闸门队列积压 | 告警阈值（>4h 未裁决）→ 通知监督者；不自动放行 |
| 追溯库写入失败 | 编排器任务暂停并持久化待写队列；禁止无追溯执行下游 |

## 9. 阶段 Go/No-Go 检查单（工程师侧）

- [ ] 上阶段验收指标全绿（数据来自看板，非手工报告）
- [ ] 回归集通过率 ≥90% 且较上版本不劣化
- [ ] 审计抽查：本阶段 100% 动作有日志、无未留痕介入
- [ ] 供应商切换演练/备份恢复演练完成并留档
- [ ] 安全加固清单逐项复核通过
- [ ] 本阶段新增资产已入库（模板/案例），RAG 命中率有监控
